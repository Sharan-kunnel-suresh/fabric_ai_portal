# Real PLC (S7-1500) - 50 p part

The SCADA talks to the real PLC with exactly the same code; only the node addressing differs.

## 1. TIA Portal
1. Create a **global DB** named `FabricPLC` (optimized block access is fine - OPC UA uses symbolic access).
2. Add the tags of `plc/tags.py` with these types: Bool, Real, Int, DInt (same names!).
3. PLC properties -> **OPC UA -> Server -> Activate OPC UA server**. Security: allow *guest* authentication for the lab
   (or set a user), and in the DB tags tick **Accessible from HMI/OPC UA** and **Writable from HMI/OPC UA**
   for the SCADA->PLC tags (Start_Cmd, Stop_Cmd, EStop, Reset_Cmd, Belt_Speed, AI_Done, AI_Result, AI_Confidence).
4. Download, then check the node ids with **UaExpert**. If the namespace index is not 3, edit `REAL_NODE_FMT` in `config.py`.
5. In the SCADA choose *Real S7-1500*, enter `opc.tcp://<PLC-IP>:4840` and press Connect.

## 2. SCL for the state machine (call it in OB1/OB30; the scan time replaces dt)
Use an FB `FB_Line` with static `State: Int; Pos: Real; Timer: TON; Defect: Bool; AiDone: Bool`.

```pascal
// pulses from the SCADA are reset by the PLC (like the simulator does)
#start := "FabricPLC".Start_Cmd; "FabricPLC".Start_Cmd := FALSE;
#stop  := "FabricPLC".Stop_Cmd;  "FabricPLC".Stop_Cmd  := FALSE;
#reset := "FabricPLC".Reset_Cmd; "FabricPLC".Reset_Cmd := FALSE;
#dt := 0.1;                         // cycle time of the OB30 in seconds

IF "FabricPLC".EStop THEN #State := 4;
ELSIF (#State = 4 OR #State = 5) AND #reset AND NOT "FabricPLC".EStop THEN #State := 0;
ELSE
  CASE #State OF
    0: IF #start THEN #State := 1; END_IF;
    1: IF #stop THEN #State := 0;
       ELSE
         #Pos := #Pos + "FabricPLC".Belt_Speed * #dt;
         IF #Pos >= 40.0 AND NOT #AiDone THEN
            #Pos := 40.0; "FabricPLC".Camera_Trigger := TRUE; #State := 2;
         ELSIF #Pos >= 75.0 AND #Defect THEN #Pos := 75.0; #State := 3;
         ELSIF #Pos >= 100.0 THEN
            "FabricPLC".Cnt_Total += 1; "FabricPLC".Cnt_Good += 1;
            "FabricPLC".Item_Id += 1; #Pos := 0.0; #AiDone := FALSE; #Defect := FALSE;
            "FabricPLC".AI_Done := FALSE;
         END_IF;
       END_IF;
    2: #T(IN := TRUE, PT := T#8s);                         // wait for the AI
       IF "FabricPLC".AI_Done THEN
          #Defect := "FabricPLC".AI_Result = 1; #AiDone := TRUE;
          "FabricPLC".Camera_Trigger := FALSE; #T(IN := FALSE); #State := 1;
       ELSIF #T.Q THEN #State := 5; #T(IN := FALSE); END_IF;
    3: #T(IN := TRUE, PT := T#1s);                         // pusher
       IF #T.Q THEN
          "FabricPLC".Cnt_Total += 1; "FabricPLC".Cnt_Rejected += 1;
          "FabricPLC".Item_Id += 1; #Pos := 0.0; #AiDone := FALSE; #Defect := FALSE;
          "FabricPLC".AI_Done := FALSE; #T(IN := FALSE); #State := 1;
       END_IF;
  END_CASE;
END_IF;

"FabricPLC".State := #State;
"FabricPLC".Motor_Run := (#State = 1);
"FabricPLC".Reject_Pusher := (#State = 3);
"FabricPLC".Lamp_Green := (#State = 1);
"FabricPLC".Lamp_Red := (#State = 4 OR #State = 5);
"FabricPLC".Item_Position := #Pos;
"FabricPLC".Item_Present := TRUE;
```
Map `Motor_Run`, `Reject_Pusher` and the lamps to the physical outputs (Q addresses) in your TIA project.
(The SCL above mirrors `plc/opcua_server.py`; it has not been run on hardware - check syntax/types in TIA.)
